# 发布后复盘（PRD 8：OODA，不把猜测升级为事实）

## 输入（用户手动录入）
平台、链接、发布时间、（可选）粉丝量、曝光/播放、完播或观看时长、点赞、评论、
收藏、转发、关注增长、数据统计时点、制作形式/时长/成本。
不同平台指标口径不直接混算。

## 复盘顺序
1. **观察**：与同平台、相近题材的历史内容对比；样本不足则明示。
2. **定向**：列出竞争解释（选题需求、标题/开头、正文、形式、分发、发布时间），
   不凭单条低播放断言"文案失败"。
3. **决策**：下一轮只提出**一个**可执行调整。
4. **行动与再观察**：记录预测与结果，更新预测-结果对照。

## 知识沉淀（写入 05_经验与复盘）
经验卡模板：适用场景 → 原问题 → 当时判断/预测 → 依据 → 采取行动 → 实际结果 →
偏差解释（假设错误/执行差异/环境变化/运气/未知）→ 可迁移条件 → 下次复核信号。

## 红线
- 播放量高≠文案因果有效；无对照不升级为规律。
- 单次数据 → 状态"待验证"；预设证据标准满足且（重要规则）用户确认后才能"已验证"。
- 禁止宣称"AI 自动训练了模型权重"。
