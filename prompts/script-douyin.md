# 抖音口播稿生成（PRD 6：每题×每平台仅 1 份初稿）

## 触发条件
用户已在第一人工关口明确选定该选题并指定抖音。否则一律不生成。

## 生成前必读（Notion）
用户已确认偏好、抖音写作规范、相关案例与反例、选题事实来源、禁用表达、上次修改记录。
时效性强的工具功能重新核验（跑一遍/查官方公告）。

## 写作假设（初始，用真实数据校正，不是平台规则）
- 口语化，开头 3 秒点出具体问题或反差，不铺垫空话；
- 主体用具体操作步骤或真实案例推进，节奏清晰，适合口播；
- 不为刺激夸大；收益/时间/效果/价格不得编造，逐条给出处；
- 结尾给可带走的一个动作（可保存/可复现）。

## 交付
标题 + 口播正文 +（可选）画面提示 + 事实核对清单 + 来源链接 + 未证实内容提醒。
不自动生成视频，不代发布（第二人工关口：用户确认最终稿）。

## 版本纪律
用户反馈后修订**同一稿件**（V1→V2→…），保存 feedback_text / interpreted_change /
change_summary / accepted_by_user / timestamp；区分"局部修改"与"用户确认的长期偏好"，
后者须用户明示才写入知识库。
